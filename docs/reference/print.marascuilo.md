# Print method for marascuilo objects

Prints a formatted tabular summary of the Marascuilo procedure results
to the console.

## Usage

``` r
# S3 method for class 'marascuilo'
print(x, ...)
```

## Arguments

- x:

  An object of class `marascuilo`.

- ...:

  Additional arguments passed to `print`.

## Value

Invisibly returns the original `marascuilo` object.
